# ADR-0011: Shape of the MCP server

Status: Accepted (2026-10-22)

## Context

Milestone 2 exposes the core verification use cases to agents over MCP. The
SDK (`mcp` 2.3, ADR-0003) offers tools, resources and prompts, several error
channels, free-text or structured results, and protocol-level logging. ChatGPT
connectors only support tools; Claude and Gemini support more. The server must
stay a thin adapter (ADR-0001) and must not leak quota or untrusted text.

## Decision

- **Tools only, all read-only.** Every tool carries
  `ToolAnnotations(read_only_hint=True, idempotent_hint=True, open_world_hint=True)`.
- **Structured output from pydantic models.** Tools return core result models
  (`CompanyVerification`, `BankAccountVerification`); the SDK publishes their
  JSON schema as `outputSchema` and sends `structured_content` plus a JSON text
  block. No prose is generated by the server.
- **`ToolError` is the only error channel the model sees.** The adapter maps
  core exceptions to short, actionable messages: invalid identifier (checked
  locally, no quota used), daily quota exhausted (blocked until midnight),
  register temporarily unavailable (try later), other register rejections
  (message passed through). Anything else surfaces as the SDK's generic error
  and is logged with a traceback.
- **Docstrings are the prompt.** Each tool's docstring states when to use it,
  what it returns, the quota cost, and that text fields are untrusted data.
  Tests assert the words "untrusted" and "never" are present.
- **One `httpx.AsyncClient` per server lifespan**, built in the `lifespan`
  context manager together with the `VerificationService`; tools reach it via
  `ctx.request_context.lifespan_context`.
- **Server name = `Settings.project_name`** (ADR-0004). Registry hosts and
  timeouts come from `Settings` too, so the MF test host is selected with
  `APP_MF_BASE_URL` only.
- **Dates are ISO strings** (`YYYY-MM-DD`) in tool inputs; parsing errors are
  `ToolError`s. Default is today in Europe/Warsaw, matching the registry.
- **Logging to stderr via stdlib `logging`**; the protocol-level `ctx.info`
  family is deprecated in the SDK and unused. `print` is banned by ruff `T20`.
- **In-memory tests** use `mcp.Client(server)` (protocol 2026-07-28 path). The
  client must enter and exit in the same task, so tests get a factory fixture
  and open the client with `async with` inside the test body.

## Consequences

- Adding a tool means: a core service method with tests, a decorated function
  in `apps/mcp/src/kyb_vetter_mcp/tools.py`, an eval scenario, and an entry in
  the prompt-injection suite if it returns register text.
- Streamable HTTP hosting (M4) reuses `build_server()` and mounts
  `streamable_http_app()`; nothing in the tools changes.
- `register_kind` in the output is a `P`/`S` enum; clients may rely on it.
